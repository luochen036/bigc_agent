## 来源与更新约定

- 优先使用 `bigc.edu.cn` 及学校部门子域名的公开资料；正文为按主题整理的摘要，不替代正式通知。
- “核验日期”表示本次查看网页的日期；有发布日期的文件另外标注发布日期。网页未标注更新时间时不推测其更新时间。
- 招生条件、收费、选课窗口和留学截止日期必须注明年度。学位授权点表不等于当年招生目录，历史活动不代表正在招募。
- 新通知调整旧规则时更新相关主题。例如静音学习仓采用 2026-06-15 的更新通知，未混入 2026-03-03 旧版预约时长。
- 图书馆动态门户及部分含图片的通知只收录已确认的入口与文字。未读取的图片、附件、登录系统中的规则不作为已核实事实。
- 文档中的服务网址可能需要登录或校内网络。源网页发布的链接不意味着已登录并验证该服务全部功能。
- 修改资料后，从仓库根目录运行 `python bigc-agent/src/build_index.py`。生成的 Chroma 索引及本地模型不提交到 Git。
